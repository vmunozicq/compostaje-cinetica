# Datos

- `raw/Compost dateset.xlsx`: archivo original de S01 (ver [`SOURCES.md`](../SOURCES.md)), sin editar. Si falta, `compostaje.data.download_raw()` lo descarga desde el commit fijado y verifica su sha256.
- `raw/LICENSE-Compost-Dataset`: licencia MIT del dataset.
- `reference/`: resultados originales de la memoria (S02), usados solo para validar.
- `processed/`: salidas intermedias generadas por scripts; no se versionan.

Solo datos públicos. No hay datos de empresas.
